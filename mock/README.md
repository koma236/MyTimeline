# MCTIMELINE プロトタイプモック

要件定義書（`docs/`）と機能定義書（`docs/features/F01〜F06`）の内容を、**HTML / CSS / 素の JavaScript だけ**で触れる形にした静的プロトタイプです。本実装（React + Spring Boot + PostgreSQL + S3）に入る前に、画面遷移・操作フロー・バリデーション文言を実際に触って検証することを目的としています。

## 起動方法

ビルド不要です。`mock/index.html` をブラウザ（Google Chrome 推奨）で直接開くだけで動きます。

```
open mock/index.html
```

- バックエンド・DB・S3 は使いません。データはブラウザの **localStorage** に保存され、リロードしても保持されます。
- 画面上部の黒いバーはモック専用の操作エリアです（本番画面には存在しません）。
  - **ユーザー切替**: シードユーザーにワンクリックでログインし直す（他人からのいいね・コメント・フォローを確認できます）
  - **データリセット**: localStorage を消してシードデータに戻す

## ファイル構成

```
mock/
├── index.html      全画面のマークアップ骨格 + <template> 群
├── css/style.css   CSS変数ベースのライトテーマ
└── js/
    ├── data.js     シードデータ（ER図のテーブル定義に対応）
    ├── store.js    localStorage 永続化 + 疑似API（F01〜F06 のエンドポイント案に1:1対応）
    ├── ui.js       共通描画部品（投稿カード・コメント・アバター・トースト等）
    └── app.js      ハッシュルーター + 各画面の描画・イベント配線
```

`js/store.js` の関数は機能定義書の API エンドポイント案に対応させてあり、本実装では**この層を Axios によるバックエンド呼び出しに差し替える**想定です。

## 画面と機能の対応

| ハッシュ | 画面 | 機能 |
|---------|------|------|
| `#/login` | SCR-01 ログイン | F01 認証 |
| `#/signup` | SCR-02 新規登録 | F01 認証（項目単位バリデーション・重複チェック） |
| `#/timeline` | SCR-03 タイムライン | F02 2タブ・F03 投稿/画像・F05 いいね |

| `#/search` | SCR-06 ユーザー検索 | F06 部分一致検索・フォロー |

## 動作確認シナリオ

1. **F01 認証**: 未ログインで `#/timeline` を開くとログイン画面へ誘導。新規登録で既存 username（`taro`）を入れると項目エラー。正しく登録するとそのままタイムラインへ。
2. **F02 タイムライン**: 「フォロー中」と「すべて」で表示件数が変わる。「もっと見る」で追加読み込み。
3. **F03 投稿**: 281文字で投稿ボタン無効。本文空＋画像なしは不可。画像は最大4枚（5枚目以降・JPEG/PNG以外・サイズ超過はエラー）。自分の投稿を削除するとコメント・いいねごと消える（他人の投稿に ⋯ は出ない）。
4. **F04 コメント**: 投稿詳細でコメント送信するとコメント数が +1。自分のコメントのみ削除可能。
5. **F05 いいね**: いいねを押すと色が変わり数が連動。タイムライン・詳細・プロフィールのどこで押しても他画面に反映。
6. **F06 フォロー/検索**: 検索で `ta` と入力すると部分一致。プロフィールでフォローするとフォロワー数 +1・ボタンが「フォロー中」に（ホバーで「フォロー解除」）。自分のプロフィールにフォローボタンは出ない。
7. **永続化**: 操作後にリロードして状態維持。「データリセット」で初期シードに戻る。

## 対象外（本番でも実装しない差別化ポイント）

インプレッション数の表示 / リツイート / DM / 通知 / ハッシュタグ・トレンドは、要件どおりモックにも含めていません。

## モックとしての割り切り

- パスワードは平文で保持しています（**本番では必ずハッシュ化して `password_hash` に保存**）。コード内にもコメントで明記しています。
- 画像は S3 ではなく FileReader で読み込んだ data URL として localStorage に保存します（容量制限があるため大量の画像投稿には向きません）。
- プロフィールの「フォロー中／フォロワー数」クリックは、一覧画面が初期スコープ外のため検索画面へ誘導します。

## 1. プロジェクト概要

### 1.1 背景・目的

X（旧 Twitter）に代表されるタイムライン型 SNS の仕組みを、学習目的で実装しながら理解することを目的とする。
テキストを中心とした短い投稿を時系列に表示し、ユーザー同士がコメント・いいね・フォローで交流できる SNS を開発する。

### 1.2 対象ユーザー

- 個人が学習用に利用するアプリだが、**複数の利用者が同時に使うこと**を前提に設計する
- 第三者が他ユーザーの投稿にいいね・コメントすることを想定し、**いいね数・コメント数を可視化**する

### 1.3 スコープ

**対象範囲:**
- ユーザー認証（新規登録・ログイン・ログアウト）
- タイムライン表示（「フォロー中」「すべて」の 2 タブ）
- 投稿（テキスト＋画像。画像は AWS S3 に保存）
- コメント（投稿へのコメント・件数表示）
- いいね（投稿へのいいね・取り消し・件数表示）
- フォロー（フォロー / フォロー解除・フォロー/フォロワー数表示）
- ユーザー検索（ユーザー名での検索、投稿・コメントからのプロフィール遷移）
- データのバックエンド DB 永続化

**対象外（X との差別化ポイントを含む）:**
- **インプレッション数（表示回数）の表示** … あえて表示しない
- **リツイート（再投稿）機能** … 用意しない
- ダイレクトメッセージ（DM）
- 通知機能
- ハッシュタグ・トレンド

### 1.4 X（Twitter）との差別化ポイント

| 項目 | 本アプリ | X（Twitter） |
|------|----------|--------------|
| インプレッション数表示 | 表示しない | 表示する |
| リツイート（再投稿） | なし | あり |
| いいね数・コメント数 | 表示する | 表示する |
| タイムライン | フォロー中 / すべて の 2 タブ | 複数タブ |

## 2. 用語定義

| 用語 | 定義 |
|------|------|
| 投稿（ポスト） | ユーザーが作成するテキスト（＋画像）の 1 件。タイムラインに時系列で並ぶ |
| タイムライン | 投稿を新しい順に一覧表示するメイン画面。「フォロー中」「すべて」の 2 タブを持つ |
| コメント | 特定の投稿に対して付けられる返信テキスト |
| いいね | 投稿への好意的な反応。1 ユーザーにつき 1 投稿 1 回まで |
| フォロー | あるユーザーが別のユーザーの投稿を追う関係。一方向 |
| フォロワー | 自分をフォローしているユーザー |
| username | ユーザーを一意に識別する ID（例: `@taro`）。検索・メンション表示に利用 |
| 表示名 | 画面に表示される名前（重複可） |

### 5.2 認証（F01）
- 新規登録：username・表示名・メールアドレス・パスワードで登録する
- ログイン：メールアドレス（または username）＋パスワードで認証する
- ログアウト：セッション（トークン）を破棄する
- 認証が必要な操作は未ログイン時に実行できない（ログイン画面へ誘導）

### 5.3 タイムライン（F02）
- メイン画面は「フォロー中」「すべて」の 2 タブ構成
  - **フォロー中:** 自分＋フォローしたユーザーの投稿を新しい順に表示
  - **すべて:** 全ユーザーの投稿を新しい順に表示（発見用）
- 各投稿に本文・画像・投稿者名・投稿日時・**いいね数**・**コメント数**を表示する
- 投稿者名クリックでプロフィール（SCR-05）へ遷移する

### 5.4 投稿・画像投稿（F03）
- テキスト本文の投稿（上限文字数は機能定義書で規定）
- 画像添付（最大 4 枚）。画像本体は AWS S3 に保存し、DB には `s3_key` を記録
- 自分の投稿のみ削除できる（削除時は配下のコメント・いいね・画像もカスケード削除）

### 5.5 コメント（F04）
- 投稿詳細画面から投稿へコメントできる
- 投稿ごとのコメント数を表示する
- 自分のコメントのみ削除できる

### 5.6 いいね（F05）
- 投稿へのいいね／取り消しができる
- 1 ユーザーにつき 1 投稿 1 回まで（UNIQUE 制約で二重いいねを防止）
- 投稿ごとのいいね数を表示する

### 5.7 フォロー・ユーザー検索（F06）
- 他ユーザーのフォロー／フォロー解除ができる（自分自身は不可）
- プロフィールでフォロー中数・フォロワー数を表示する
- ユーザー検索：username / 表示名の部分一致で検索できる
- 投稿・コメント・検索結果のユーザー名クリックでプロフィールへ遷移し、そこからフォローできる

### 5.8 プロフィール表示・編集（F07）
- 他ユーザーのプロフィール（表示名・`@username`・自己紹介・アバター画像・投稿一覧）を閲覧できる
- 自分のプロフィールは表示名・自己紹介・アバター画像を編集できる
- username とメールアドレスは変更できない（参照先の URL とログイン手段のため、別の手続きとする）
- 投稿・コメントのユーザー名とアバターはプロフィールへのリンクになる

### 5.9 データ保存
- ユーザー・投稿・画像メタ・コメント・いいね・フォロー関係はバックエンド DB（PostgreSQL）に保存する
- 画像本体（投稿画像・アバター画像）は AWS S3 に保存し、DB にはキーのみを記録する（ローカル開発では S3 互換の MinIO）
- ページをリロードしてもデータが保持される

### 5.10 対象外機能
- インプレッション数（表示回数）の表示
- リツイート（再投稿）
- ダイレクトメッセージ（DM）
- 通知機能
- ハッシュタグ・トレンド

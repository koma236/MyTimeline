# 機能定義書 F03: 投稿・画像投稿（S3）

**関連:** 要件 [04_features.md](../04_features.md) 5.4 / ユースケース [03_usecases.md](../03_usecases.md) UC-05・UC-06 / 画面 [06_ui_design.md](../06_ui_design.md) SCR-03・SCR-04 / データ [07_er_diagram.md](../07_er_diagram.md) `posts`・`post_images` / インフラ [09_infrastructure.md](../09_infrastructure.md)

## 1. 概要 / 目的
テキスト（＋画像）による投稿を作成・削除する。画像は AWS S3 に保存し、DB には `s3_key` のみを記録する。

## 2. 機能詳細
- **投稿作成:** 本文を入力し、必要に応じて画像（最大 4 枚）を添付して投稿する
- 投稿はタイムラインの先頭（新しい順）に反映される
- **投稿削除:** 自分の投稿のみ削除できる。削除時は配下の画像・コメント・いいねもカスケード削除する
- **画像アップロードフロー（想定）:**
  1. クライアントがアップロード用の署名付き URL（pre-signed URL）を要求
  2. クライアントが S3 に直接アップロード
  3. 投稿作成 API に `s3_key` を渡してメタデータを保存

## 3. 対象画面
- SCR-03 タイムライン画面（投稿フォーム）
- SCR-04 投稿詳細画面（投稿本体・削除メニュー）

## 4. API エンドポイント案

| メソッド | パス | 説明 | 認証 |
|----------|------|------|------|
| POST | `/api/uploads/presign` | 画像アップロード用の署名付き URL を発行 | 要 |
| POST | `/api/posts` | 投稿作成（body, image_keys[]） | 要 |
| GET | `/api/posts/{id}` | 投稿詳細取得 | 要 |
| DELETE | `/api/posts/{id}` | 投稿削除（本人のみ） | 要 |

## 5. データ
- `posts`（id, user_id, body, created_at, updated_at）
- `post_images`（id, post_id, s3_key, position, created_at）
- 画像本体は S3（画像バケット）に保存

## 6. バリデーション / 制約
- 本文：最大文字数（暫定 280 文字。[08_constraints.md](../08_constraints.md) TBD-04）。本文が空かつ画像も無い場合は投稿不可
- 画像：最大 4 枚。形式は JPEG / PNG、1 枚あたりサイズ上限（暫定・数 MB。TBD-05）
- 認可：削除は投稿の所有者のみ（他人の投稿は削除ボタン非表示＋API でも 403）

## 7. エラーハンドリング / 異常系
- 文字数超過・形式不正・枚数超過：投稿前にエラー表示
- S3 アップロード失敗：リトライ導線を表示し、失敗した画像は投稿に含めない
- 他人の投稿削除要求：403
- 存在しない投稿の取得/削除：404

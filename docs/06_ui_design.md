# 7. 画面設計

### 7.1 画面一覧

| 画面ID | 画面名 | 説明 |
|--------|--------|------|
| SCR-01 | ログイン画面 | メール/ユーザー名＋パスワードでログイン。新規登録への導線 |
| SCR-02 | 新規登録画面 | username・表示名・メール・パスワードを入力してアカウント作成 |
| SCR-03 | タイムライン画面（メイン） | 「すべて／フォロー中」タブ切替＋投稿フォーム＋投稿一覧 |
| SCR-04 | 投稿詳細画面 | 投稿本体＋コメント一覧＋コメント入力フォーム |
| SCR-05 | プロフィール画面 | 対象ユーザーの情報・フォロー/フォロワー数・投稿一覧・フォローボタン |
| SCR-06 | ユーザー検索画面 | username/表示名の部分一致検索＋結果一覧（フォローボタン付き） |
| SCR-07 | プロフィール編集画面 | 自分の表示名・自己紹介・プロフィール画像を編集 |

> **共通ルール:** 投稿・コメント・検索結果に表示されるユーザー名（表示名 / @username）は、すべてプロフィール（SCR-05）へのリンクとする。

### 7.3 ログイン画面（SCR-01）

```
┌────────────────────────────────────┐
│            MYTIMELINE               │
├────────────────────────────────────┤
│  メール または ユーザー名           │
│  ┌──────────────────────────────┐  │
│  │                              │  │
│  └──────────────────────────────┘  │
│  パスワード                         │
│  ┌──────────────────────────────┐  │
│  │                              │  │
│  └──────────────────────────────┘  │
│           [   ログイン   ]          │
│                                     │
│  アカウントをお持ちでない方 → 新規登録│
└────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| メール/ユーザー名・パスワード | ログイン入力欄 |
| `[ログイン]` | 認証を実行。失敗時はエラーメッセージを表示 |
| `新規登録` | 新規登録画面（SCR-02）へ遷移 |

### 7.4 新規登録画面（SCR-02）

```
┌────────────────────────────────────┐
│          アカウント作成             │
├────────────────────────────────────┤
│  ユーザー名 (@username)             │
│  ┌──────────────────────────────┐  │
│  表示名                             │
│  ┌──────────────────────────────┐  │
│  メールアドレス                     │
│  ┌──────────────────────────────┐  │
│  パスワード                         │
│  ┌──────────────────────────────┐  │
│           [   登録する   ]          │
│                                     │
│  すでにアカウントをお持ちの方 → ログイン│
└────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| ユーザー名 | 一意な username。重複時はエラー |
| 表示名 | 画面表示用の名前（重複可） |
| メール・パスワード | 認証情報。メール重複時はエラー |
| `[登録する]` | アカウント作成しログイン状態でタイムラインへ遷移 |

### 7.5 タイムライン画面（SCR-03・メイン）

```
┌──────────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────────┤
│  [ すべて ]  [ フォロー中 ]        ← タブ切替               │
├──────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────┐│
│  │ いま何してる？                                        ││
│  │ ┌──────────────────────────────────────────────────┐ ││
│  │ │                                                  │ ││
│  │ └──────────────────────────────────────────────────┘ ││
│  │ [🖼 画像を追加(最大4枚)]                    [ 投稿 ]  ││
│  └──────────────────────────────────────────────────────┘│
│  ────────────────────────────────────────────────────────│
│  ┌──────────────────────────────────────────────────────┐│
│  │ 山田太郎 @taro ・ 3分前                        [ ⋯ ] ││
│  │ 今日はいい天気！散歩してきた。                        ││
│  │ ┌────────┐┌────────┐                                 ││
│  │ │ 画像1  ││ 画像2  │                                 ││
│  │ └────────┘└────────┘                                 ││
│  │   ♥ 12    💬 3                                        ││
│  └──────────────────────────────────────────────────────┘│
│  ┌──────────────────────────────────────────────────────┐│
│  │ 佐藤花子 @hanako ・ 1時間前                          ││
│  │ 新しいカフェ行ってきました☕                          ││
│  │   ♥ 5     💬 1                                        ││
│  └──────────────────────────────────────────────────────┘│
│                       （以下、新しい順に続く）             │
└──────────────────────────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| `[すべて] [フォロー中]` | タイムラインのタブ切替。すべて＝全ユーザー（初期選択）、フォロー中＝自分＋フォロー先 |
| 投稿フォーム | 本文入力＋画像添付（最大 4 枚）＋投稿ボタン |
| ユーザー名 `@taro` | クリックでプロフィール（SCR-05）へ遷移 |
| `♥ 12` | いいねボタン＋いいね数。クリックでいいね/取り消し。自分がいいね済みは色付き表示 |
| `💬 3` | コメント数。クリックで投稿詳細（SCR-04）へ遷移 |
| `[⋯]` | 自分の投稿のみ表示されるメニュー（削除） |
| `[🔍 検索]` | ユーザー検索画面（SCR-06）へ遷移 |

│  │ 今日はいい天気！散歩してきた。   ♥12 💬3   ││
│  └──────────────────────────────────────────┘│
│  ┌──────────────────────────────────────────┐│

| 要素 | 説明 |
|------|------|
| プロフィール画像 | 未設定なら表示名の頭文字を表示（F07） |
| 表示名 / @username / 自己紹介 | 対象ユーザーの基本情報 |
| 利用開始年月 | `created_at` から「2026年1月から利用」の形で表示 |

| `[プロフィールを編集]` | 自分のプロフィールでのみ表示。SCR-07 へ遷移（F07） |
| 投稿一覧 | 対象ユーザーの投稿を新しい順に表示（無限スクロール） |

### 7.9 プロフィール編集画面（SCR-07）

```
┌──────────────────────────────────────────────┐
│ ← プロフィール                                 │
├──────────────────────────────────────────────┤
│  プロフィールを編集                             │
│                                                 │
│  プロフィール画像                               │
│  ┌────┐  [ 画像を選択 ]                        │
│  │画像│  [ 画像を削除 ]                        │
│  │    │  JPEG または PNG・2MB まで              │
│  └────┘                                        │
│                                                 │
│  表示名                                         │
│  ┌──────────────────────────────────────────┐│
│  └──────────────────────────────────────────┘│
│  自己紹介                                       │
│  ┌──────────────────────────────────────────┐│
│  │                                            ││
│  └──────────────────────────────────────────┘│
│                                        残り 280 │
│           [      保存する      ]                │
└──────────────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| プロフィール画像 | `[画像を選択]` で差し替え、`[画像を削除]` で既定の表示（表示名の頭文字）に戻す。**どちらも押した時点で即時反映**し、下のフォームとは独立して動く |
| 表示名 | 必須・100 文字以内。エラー文言はサーバーの `fieldErrors` をそのまま表示 |
| 自己紹介 | 任意・300 文字以内。残り文字数を表示し、超過すると保存ボタンを無効化 |
| `[保存する]` | 表示名と自己紹介を更新し、プロフィール（SCR-05）へ戻る |

> **プロフィール画像をフォームと分けている理由:** 1 つの保存ボタンで JSON（表示名・自己紹介）と画像を続けて送ると、片方だけ成功したときに「何が保存されて何が保存されていないのか」をユーザーに説明できなくなるため。

# 7. 画面設計

### 7.1 画面一覧

| 画面ID | 画面名 | 説明 |
|--------|--------|------|
| SCR-01 | ログイン画面 | メール/ユーザー名＋パスワードでログイン。新規登録への導線 |
| SCR-02 | 新規登録画面 | username・表示名・メール・パスワードを入力してアカウント作成 |
| SCR-03 | タイムライン画面（メイン） | 「フォロー中／すべて」タブ切替＋投稿フォーム＋投稿一覧 |
| SCR-04 | 投稿詳細画面 | 投稿本体＋コメント一覧＋コメント入力フォーム |
| SCR-05 | プロフィール画面 | 対象ユーザーの情報・フォロー/フォロワー数・投稿一覧・フォローボタン |
| SCR-06 | ユーザー検索画面 | username/表示名の部分一致検索＋結果一覧（フォローボタン付き） |

> **共通ルール:** 投稿・コメント・検索結果に表示されるユーザー名（表示名 / @username）は、すべてプロフィール（SCR-05）へのリンクとする。

### 7.3 ログイン画面（SCR-01）

```
┌────────────────────────────────────┐
│            MCTIMELINE               │
├────────────────────────────────────┤
│  メール または ユーザー名           │
│  ┌──────────────────────────────┐  │
│  │                              │  │
│  └──────────────────────────────┘  │
│  パスワード                         │
│  ┌──────────────────────────────┐  │
│  │                              │  │
│  └──────────────────────────────┘  │
│           [   ログイン   ]          │
│                                     │
│  アカウントをお持ちでない方 → 新規登録│
└────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| メール/ユーザー名・パスワード | ログイン入力欄 |
| `[ログイン]` | 認証を実行。失敗時はエラーメッセージを表示 |
| `新規登録` | 新規登録画面（SCR-02）へ遷移 |

### 7.4 新規登録画面（SCR-02）

```
┌────────────────────────────────────┐
│          アカウント作成             │
├────────────────────────────────────┤
│  ユーザー名 (@username)             │
│  ┌──────────────────────────────┐  │
│  表示名                             │
│  ┌──────────────────────────────┐  │
│  メールアドレス                     │
│  ┌──────────────────────────────┐  │
│  パスワード                         │
│  ┌──────────────────────────────┐  │
│           [   登録する   ]          │
│                                     │
│  すでにアカウントをお持ちの方 → ログイン│
└────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| ユーザー名 | 一意な username。重複時はエラー |
| 表示名 | 画面表示用の名前（重複可） |
| メール・パスワード | 認証情報。メール重複時はエラー |
| `[登録する]` | アカウント作成しログイン状態でタイムラインへ遷移 |

### 7.5 タイムライン画面（SCR-03・メイン）

```
┌──────────────────────────────────────────────────────────┐
│ MCTIMELINE            [🔍 検索]  [自分のプロフィール] [ログアウト]│
├──────────────────────────────────────────────────────────┤
│  [ フォロー中 ]  [ すべて ]        ← タブ切替               │
├──────────────────────────────────────────────────────────┤
│  ┌──────────────────────────────────────────────────────┐│
│  │ いま何してる？                                        ││
│  │ ┌──────────────────────────────────────────────────┐ ││
│  │ │                                                  │ ││
│  │ └──────────────────────────────────────────────────┘ ││
│  │ [🖼 画像を追加(最大4枚)]                    [ 投稿 ]  ││
│  └──────────────────────────────────────────────────────┘│
│  ────────────────────────────────────────────────────────│
│  ┌──────────────────────────────────────────────────────┐│
│  │ 山田太郎 @taro ・ 3分前                        [ ⋯ ] ││
│  │ 今日はいい天気！散歩してきた。                        ││
│  │ ┌────────┐┌────────┐                                 ││
│  │ │ 画像1  ││ 画像2  │                                 ││
│  │ └────────┘└────────┘                                 ││
│  │   ♥ 12    💬 3                                        ││
│  └──────────────────────────────────────────────────────┘│
│  ┌──────────────────────────────────────────────────────┐│
│  │ 佐藤花子 @hanako ・ 1時間前                          ││
│  │ 新しいカフェ行ってきました☕                          ││
│  │   ♥ 5     💬 1                                        ││
│  └──────────────────────────────────────────────────────┘│
│                       （以下、新しい順に続く）             │
└──────────────────────────────────────────────────────────┘
```

| 要素 | 説明 |
|------|------|
| `[フォロー中] [すべて]` | タイムラインのタブ切替。フォロー中＝自分＋フォロー先、すべて＝全ユーザー |
| 投稿フォーム | 本文入力＋画像添付（最大 4 枚）＋投稿ボタン |
| ユーザー名 `@taro` | クリックでプロフィール（SCR-05）へ遷移 |
| `♥ 12` | いいねボタン＋いいね数。クリックでいいね/取り消し。自分がいいね済みは色付き表示 |
| `💬 3` | コメント数。クリックで投稿詳細（SCR-04）へ遷移 |
| `[⋯]` | 自分の投稿のみ表示されるメニュー（削除） |
| `[🔍 検索]` | ユーザー検索画面（SCR-06）へ遷移 |

```
├──────────────────────────────────────────────┤

│ ┌──────────────────────────────────┐ [ 送信 ] │

│ 鈴木一郎 @ichiro ・ 2分前              [ ⋯ ]   │
```

| 要素 | 説明 |
|------|------|
| 投稿本体 | タイムラインの投稿カードと同内容（いいね数・コメント数含む） |
| コメント入力フォーム | 本文入力＋送信。送信でコメント一覧に追加、コメント数 +1 |
| コメント一覧 | 投稿へのコメントを時系列で表示。ユーザー名はプロフィールへリンク |
| コメントの `[⋯]` | 自分のコメントのみ表示されるメニュー（削除） |

```
│  山田太郎                                       │

│  自己紹介: 散歩と写真が好きです。               │
│                                                 │
│  フォロー中 45   フォロワー 120     [ フォロー ]│
├──────────────────────────────────────────────┤
│  投稿一覧                                       │
│  ┌──────────────────────────────────────────┐│
│  │ 今日はいい天気！散歩してきた。   ♥12 💬3   ││
│  └──────────────────────────────────────────┘│
│  ┌──────────────────────────────────────────┐│
```

| 要素 | 説明 |
|------|------|
| 表示名 / @username / 自己紹介 | 対象ユーザーの基本情報 |
| フォロー中数・フォロワー数 | それぞれ `follows` の集計値 |
| `[フォロー]` ボタン | フォロー/フォロー解除の切替。フォロー済みは「フォロー中」表示。自分のプロフィールでは非表示 |
| 投稿一覧 | 対象ユーザーの投稿を新しい順に表示 |

```
│     └────────────────────────────────────┘    │
├──────────────────────────────────────────────┤
│  検索結果                                       │
│  ┌──────────────────────────────────────────┐│

│  ┌──────────────────────────────────────────┐│
│  │ 田中太一 @taichi              [フォロー中] ││

```

| 要素 | 説明 |
|------|------|
| 検索バー | username / 表示名の部分一致で検索。未入力時は全ユーザー/新着ユーザーを表示 |
| 検索結果カード | 表示名・@username・自己紹介・フォローボタン。ユーザー名クリックでプロフィール（SCR-05）へ遷移 |
| `[フォロー] / [フォロー中]` | フォロー状態に応じて切り替わるボタン |
